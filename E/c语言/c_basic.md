## 1. 字符串字面量是常量吗？

**字符串字面量的内容不能修改，但在 C99 中，它的类型不带 `const`。**

例如：

```c
"Hello"
```

在 C99 中，普通字符串字面量的类型是 `char[N]`，具有静态存储期。

`"Hello"` 实际包含 6 个字符：

```text
'H' 'e' 'l' 'l' 'o' '\0'
```

其中 `\0` 是字符串结束标志。

## 2. 为什么不能修改字符串字面量？

```c
char *p = "Hello";
p[0] = 'A';  // 未定义行为
```

- `p` 是指针变量。
- `p` 指向字符串字面量的第一个字符。
- 修改字符串字面量会产生未定义行为（Undefined Behavior）。

推荐写法：

```c
const char *p = "Hello";
```

这样编译器可以阻止通过 `p` 修改所指向的字符。

## 3. 为什么字符数组可以修改？

```c
char *p = "Hello";
char s[] = "Hello";
```

- 第一种：`p` 指向字符串字面量，不能修改字面量内容。
- 第二种：`s` 是独立的字符数组，内容可以修改。

例如：

```c
char s[] = "Hello";
s[0] = 'A';
```

修改后，数组中的字符串变成 `"Aello"`。

## 4. const char *p 能否改变指向？

```c
const char *p = "Hello";
p = "World";  // 合法
```

**可以修改指针保存的地址，但不能通过它修改所指向的字符。**

比较：

```c
char s[] = "Hello";

const char *p = "Hello";        // p 可以改变指向
char *const q = s;             // q 不能改变指向
const char *const r = "Hello"; // r 不能改变指向，也不能通过 r 修改字符
```

## 5. 总结

| 写法 | 能否修改字符内容 | 能否改变指向 |
|---|---|---|
| `char *p = "Hello";` | 不能修改字面量 | 可以 |
| `const char *p = "Hello";` | 不能通过 p 修改 | 可以 |
| `char s[] = "Hello";` | 可以修改数组 | 数组名不能重新赋值 |
| `char *const q = s;` | 可以修改数组内容 | 不可以 |

## 核心记忆

1. 字符串字面量的内容不能修改。
2. C99 普通字符串字面量的类型是 `char[N]`。
3. `char *p = "Hello";` 创建指针，指向字符串字面量。
4. `char s[] = "Hello";` 创建独立的字符数组。
5. `const char *p` 限制通过指针修改字符，不限制指针重新赋值。

**指针能否改变指向，与所指向内容能否修改，是两个不同的问题。**

<details>
<summary><strong>📖 C 语言：转义序列与转换说明的区别</strong></summary>

### 一、核心区别

**转义序列（Escape Sequence）在编译时处理，而转换说明（Conversion Specification）在运行时由 `printf` 处理。**

虽然它们都出现在字符串中，但**处理者、处理时间和作用完全不同**。

| 比较 | 转义序列 `\n` | 转换说明 `%d` |
|---|---|---|
| 处理者 | 编译器 | `printf` 函数 |
| 处理时间 | 编译时 | 运行时 |
| 作用 | 表示特殊字符 | 指示如何格式化参数 |
| 编译后 | 成为一个换行字符 | `%d` 原样保留 |
| 是否依赖 `printf` | 否 | 需要支持相应格式的函数解析 |

**一句话理解：`\n` 是 C 语言字符串的语法，`%d` 是 `printf` 的格式规则。**

### 二、从编译到运行经历了什么？

先看一个简单的例子：

```c
int age = 18;
printf("Age: %d\n", age);
```

最终输出：

```text
Age: 18
```

这里有两个特殊的东西：

- `\n`：转义序列，表示一个换行字符。
- `%d`：转换说明，告诉 `printf` 把对应的整数参数转换为十进制文本输出。

**关键是：它们不是同时被处理的。**

**① 编译阶段：处理转义序列**

源代码中的字符串：

```c
"Age: %d\n"
```

编译器识别 `\n`，将其转换成一个换行字符。

编译后的字符串内容可以理解为：

```text
A  g  e  :  ␣  %  d  LF  \0
```

其中：

- `␣`：空格字符。
- `LF`：换行字符。
- `\0`：字符串结束标记（空字符）。
- `%d`：仍然是 `%` 和 `d` 两个普通字符。

因此：

- `\n` 在源代码中写成两个字符，编译后表示一个换行字符。
- `%d` 不会在编译阶段被替换成数字。

**② 运行阶段：`printf` 解析转换说明**

程序运行时执行：

```c
printf("Age: %d\n", age);
```

`printf` 读取格式字符串：

1. 遇到普通字符 `Age: `，直接输出。
2. 遇到 `%d`，读取对应的整数参数 `age`。
3. 将整数 `18` 转换成十进制文本输出。
4. 遇到换行字符，输出换行。

最终输出：

```text
Age: 18
```

### 三、什么是格式字符串（Format String）？

在 `printf` 中，**第一个参数就是格式字符串（Format String）**。

注意：是**第一个参数**，不是程序的第一句。

`printf` 的函数声明是：

```c
int printf(const char *format, ...);
```

其中：

- `int`：函数返回值类型，成功时返回输出的字符数。
- `printf`：函数名。
- `const char *format`：第一个参数，即格式字符串。
- `...`：可变参数，表示后面可以接收数量不定的参数。

**格式字符串相当于给 `printf` 的说明书，后面的参数则提供需要输出的数据。**

例如：

```c
printf("%s", "Number: %d\n");
```

这里有两个参数：

| 参数 | 内容 | 作用 |
|---|---|---|
| 第一个 | `"%s"` | 格式字符串，告诉 `printf` 如何输出 |
| 第二个 | `"Number: %d\n"` | 普通字符串参数，提供实际输出内容 |

### 四、为什么第二个参数中的 `%d` 不会被解析？

比较下面两种写法。

**① 第一种：`%d` 位于普通字符串参数中**

```c
printf("%s", "Number: %d\n");
```

执行过程：

1. `printf` 读取第一个参数 `"%s"`。
2. 发现 `%s`，表示从后面的参数中读取一个字符串并输出其内容。
3. 读取第二个参数 `"Number: %d\n"`。
4. 直接输出第二个参数的字符串内容，不会再次解析其中的 `%d`。

最终输出：

```text
Number: %d
```

**为什么 `%d` 没有被替换？**

因为 `printf` **只解析格式字符串中的转换说明，不会递归解析通过 `%s` 输出的字符串。**

注意：

- 第二个参数中的 `%d` 只是普通字符。
- 第二个参数中的 `\n` 在编译阶段已经转换为换行字符，因此仍然会换行。

**② 第二种：`%d` 位于格式字符串中**

```c
printf("Number: %d\n", 123);
```

这次：

1. 第一个参数 `"Number: %d\n"` 是格式字符串。
2. `%d` 位于格式字符串中，因此会被解析。
3. 第二个参数 `123` 是提供给 `%d` 的整数。

最终输出：

```text
Number: 123
```

**关键区别：**

```c
printf("%s", "Number: %d\n");  // 输出 Number: %d
printf("Number: %d\n", 123);   // 输出 Number: 123
```

- 第一种：`%d` 位于普通字符串参数中，不会被解析。
- 第二种：`%d` 位于格式字符串中，会被解析。

因此，**`%d` 本身并没有特殊能力，只有被支持相应格式的函数当作转换说明解析时，才具有特殊含义。**

### 五、为什么 `%d` 不在编译时处理？

考虑下面的程序：

```c
int a;
scanf("%d", &a);
printf("Number: %d\n", a);
```

编译的时候，编译器知道格式字符串中有 `%d`，但是它不知道用户运行程序时会输入什么整数。

假设用户输入 `25`，那么运行时 `printf` 才能根据变量 `a` 的实际值输出：

```text
Number: 25
```

因此：

- `\n` 的含义是固定的，不需要其他参数，编译器可以直接把它转换成换行字符。
- `%d` 是转换说明，具体输出什么取决于运行时对应参数的值。

不过，格式字符串中不一定要包含转换说明。

例如：

```c
printf("Hello World\n");
```

同样合法，因为 `printf` 可以直接输出格式字符串中的普通字符和换行字符。

### 六、综合示例

```c
printf("%s %d\n", "Age:", 18);
```

这里有三个参数：

| 参数 | 内容 | 作用 |
|---|---|---|
| 第一个 | `"%s %d\n"` | 格式字符串 |
| 第二个 | `"Age:"` | 提供给 `%s` 的字符串 |
| 第三个 | `18` | 提供给 `%d` 的整数 |

格式字符串中的内容与参数对应关系如下：

| 内容 | 对应参数 | 作用 |
|---|---|---|
| `%s` | `"Age:"` | 输出字符串 |
| 空格 | 不需要参数 | 输出空格 |
| `%d` | `18` | 输出十进制整数 |
| `\n` | 不需要参数 | 输出换行字符 |

最终输出：

```text
Age: 18
```

注意：`%s` 和 `%d` 是转换说明，需要对应的数据参数；`\n` 是转义序列，不需要额外参数。

### 七、总结

1. **`\n` 是转义序列**，由编译器在编译时处理。
2. **`%d` 是转换说明**，由 `printf` 在运行时解析。
3. `printf` 的第一个参数是格式字符串，后面的参数通常用于提供数据。
4. 格式字符串中的转换说明决定如何格式化对应参数。
5. 普通字符串参数中的 `%d` 不会被 `printf` 再次解析。
6. 转义序列的处理与字符串是否作为 `printf` 的格式字符串无关。

**最终理解：**

- **编译器负责解释 C 语言字符串中的转义序列。**
- **`printf` 负责解释格式字符串中的转换说明。**

注意：以上是通常的 C 语言执行模型。实际编译器在优化时可能提前处理某些确定的 `printf` 调用，但不影响理解两者的区别。

### 一、常见字符的表示方法

| 想表示的字符 | 字符常量 | 字符串字面量 |
|---|---|---|
| 单引号 `'` | `'\''` | `"'"` |
| 双引号 `"` | `'"'` 或 `'\"'` | `"\""` |
| 反斜杠 `\` | `'\\'` | `"\\"` |
| 问号 `?` | `'?'` 或 `'\?'` | `"?"` 或 `"\?"` |
| 换行符 | `'\n'` | `"\n"` |
| 字母 `n` | `'n'` | `"n"` |

**注意：**
- 单引号 `' '` 表示字符常量。
- 双引号 `" "` 表示字符串字面量。
- `\` 是转义序列的引导符，但不是所有字符都需要转义。
- `\n` 表示一个换行字符，而 `n` 只是普通字母。

---

### 二、如何使用 printf 输出特殊字符？

| 想输出的内容 | printf 写法 | 原因 |
|---|---|---|
| 字母 `n` | `printf("n");` | 普通字符，直接输出 |
| 换行 | `printf("\n");` | `\n` 表示换行字符 |
| 字面上的 `\n` | `printf("\\n");` | `\\` 表示反斜杠，`n` 是普通字符 |
| 反斜杠 `\` | `printf("\\");` | `\\` 表示一个反斜杠 |
| 双引号 `"` | `printf("\"");` | `\"` 表示双引号 |
| 单引号 `'` | `printf("'");` | 单引号在字符串中不需要转义 |
| 百分号 `%` | `printf("%%");` | `%%` 是 printf 规定的写法 |
| 问号 `?` | `printf("?");` | 普通字符，直接输出 |

例如：

```c
printf("n");     // 输出 n
printf("\n");    // 真正换行
printf("\\n");   // 输出 \n
printf("\\\\n"); // 输出 \\n
```

### 三、为什么 \n 和 \\n 不一样？

```c
printf("\n");
```

编译器把 `\n` 识别为一个完整的转义序列，表示换行字符。

而：

```c
printf("\\n");
```

编译器从左到右识别：

- `\\`：表示一个反斜杠字符。
- `n`：普通字母。

所以最终输出两个字符：

```text
\n
```

**核心区别：**

- `n`：普通字母。
- `\n`：一个换行字符。
- `\\n`：一个反斜杠字符加一个字母 `n`。

---

### 四、为什么 % 不能使用 \ 转义？

因为 C 语言的转义序列与 `printf` 的转换说明是两套不同的规则。

| 对比 | 转义序列 | 转换说明 |
|---|---|---|
| 引导符 | `\` | `%` |
| 示例 | `\n`、`\\`、`\"` | `%d`、`%c`、`%%` |
| 处理者 | C 编译器 | `printf` 函数 |
| 处理阶段 | 编译时 | 运行时 |
| 作用 | 表示特殊字符 | 控制格式化输出 |

例如：

```c
printf("%%");        // 正确：输出 %
printf("%c", '%');   // 正确：输出 %
printf("%s", "%");   // 正确：输出 %

printf("\%");        // 错误：\% 不是标准 C 转义序列
printf("%");         // 错误：格式说明不完整
```

**总结：**

1. 普通字符直接写，例如 `n`、`A`、`?`。
2. C 语言规定的特殊字符可以通过转义序列表示，例如 `\n`、`\\`、`\"`。
3. 想输出字面上的反斜杠，需要写 `\\`。
4. `printf` 中想直接输出 `%`，使用 `%%`。
5. 转义序列由编译器处理，转换说明由 `printf` 在运行时处理。

<details>
<summary><strong>C 语言：printf 格式字符串、数组与指针</strong></summary>

### 一、为什么 printf 不能使用单引号？

首先看 `printf` 的函数声明：

```c
int printf(const char *format, ...);
```

各部分的含义：

| 部分 | 含义 |
|---|---|
| `int` | 函数返回值类型 |
| `printf` | 函数名称 |
| `const char *` | 指向字符的指针，不允许通过该指针修改字符 |
| `format` | 格式字符串参数 |
| `...` | 可变参数，可以传递其他值 |

**关键：`printf` 的第一个参数必须是指向有效字符串的指针。**

例如：

```c
printf("A");        // 正确
printf('A');        // 错误用法
printf("%c", 'A');  // 正确
```

为什么？

因为 C 语言中，单引号与双引号的含义不同。

| 写法 | 含义 | 类型 |
|---|---|---|
| `'A'` | 字符常量 | `int` |
| `"A"` | 字符串字面量 | `char[2]` |
| `'AB'` | 多字符常量 | `int` |
| `"ABC"` | 字符串字面量 | `char[4]` |

`'A'` 是一个整数值，而 `"A"` 是包含 `'A'` 和 `'\0'` 的字符数组。

因此：

- `printf('A')`：传入 `int`，不符合第一个参数的类型要求。
- `printf("A")`：数组自动转换为指向第一个字符的指针，符合要求。
- `printf("%c", 'A')`：第一个参数是格式字符串，第二个参数是字符值，符合要求。

**注意：C 语言允许多字符常量，例如 `'AB'`，但其类型依然是 `int`，不能当作格式字符串使用。**

---

### 二、为什么 "ABC" 没有 & 也能传递地址？

例如：

```c
printf("ABC");
```

这里的 `"ABC"` 本身不是指针，而是一个字符串字面量。

在 C 语言中，它的类型是：

```c
char[4]
```

内存结构可以理解为：

| 地址（示意） | 内容 | 数组下标 |
|---|---|---|
| 0x1000 | `'A'` | `[0]` |
| 0x1001 | `'B'` | `[1]` |
| 0x1002 | `'C'` | `[2]` |
| 0x1003 | `'\0'` | `[3]` |

为什么是四个字符？

因为字符串字面量会自动包含一个结尾的空字符 `'\0'`。

**关键：数组表达式在大多数情况下会自动转换为指向其首元素的指针。**

这种机制叫作：

**数组到指针的转换（Array-to-Pointer Conversion）。**

例如：

```c
char str[] = "ABC";

char *p = str;
```

在这里：

```c
char *p = str;
```

与：

```c
char *p = &str[0];
```

具有相同的效果。

因为在这个表达式中，`str` 会自动转换为首元素地址。

因此：

```c
printf("ABC");
```

可以理解为以下过程：

1. `"ABC"` 是一个 `char[4]` 数组。
2. 作为函数实参时，自动转换为指向第一个字符的 `char *`。
3. 该指针可以转换为 `const char *`。
4. `printf` 接收到首元素地址，开始读取字符串。
5. 遇到 `'\0'` 时停止。

**注意：数组不是指针，只是在大多数表达式中会自动转换为指针。**

例如，`sizeof` 直接作用于数组时，不会发生这种转换。

---

### 三、为什么 str 和 &str[0] 都可以？

例如：

```c
char str[] = "ABC";

printf("%s", str);
printf("%s", &str[0]);
```

两条语句都会输出：

```text
ABC
```

原因：

- `str`：数组在这里自动转换为指向首元素的指针。
- `&str[0]`：显式获取首元素的地址。

因此，在这个场景中：

```c
str
```

与：

```c
&str[0]
```

产生相同的指针值。

**注意：`"%s"` 才是 `printf` 的格式字符串，`str` 是第二个参数，提供要输出的字符串的首地址。**

---

### 四、为什么 str + 1 会输出 BC？

例如：

```c
char str[] = "ABC";

printf("%s", str + 1);
```

输出：

```text
BC
```

内存结构：

| 下标 | 内容 | 指针位置 |
|---|---|---|
| `str[0]` | `'A'` | `str` |
| `str[1]` | `'B'` | `str + 1` |
| `str[2]` | `'C'` | `str + 2` |
| `str[3]` | `'\0'` | `str + 3` |

这里：

- `str` 指向 `'A'`。
- `str + 1` 指向 `'B'`。
- `%s` 从指定地址开始输出字符，直到遇见 `'\0'`。

因此输出 `BC`。

**注意：`str + 1` 并没有修改数组，只是让读取的起始位置向后移动了一个字符。**

---

### 五、str + 1 和 *(str + 1) 有什么区别？

例如：

```c
char str[] = "ABC";

printf("%s", str + 1);
printf("%c", *(str + 1));
```

两者区别：

| 表达式 | 含义 | 结果 |
|---|---|---|
| `str` | 首元素地址 | 指向 `'A'` |
| `str + 1` | 第二个元素地址 | 指向 `'B'` |
| `*(str + 1)` | 解引用，读取第二个元素 | `'B'` |
| `str[1]` | 访问第二个元素 | `'B'` |

因此：

```c
printf("%s", str + 1);     // 输出 BC
printf("%c", *(str + 1));  // 输出 B
```

这里：

- `%s`：需要指向字符串的指针。
- `%c`：需要字符值（以 `int` 类型传入）。
- `*`：解引用运算符，通过指针访问它指向的对象。

在这里：

```c
*(str + 1) == str[1]
```

两者都表示字符 `'B'`。

---

### 六、总结

**1. 单引号与双引号**

- `'A'`：字符常量，类型为 `int`。
- `"A"`：字符串字面量，类型为 `char[2]`。

**2. printf 的参数**

- 第一个参数：格式字符串的首地址。
- 其他参数：根据格式说明传入相应的值。

**3. 数组与指针**

- 数组本身不是指针。
- 数组表达式在大多数情况下自动转换为指向首元素的指针。
- `str` 和 `&str[0]` 在上述场景中产生相同的指针值。

**4. 指针运算与解引用**

- `str + 1`：指向下一个字符。
- `*(str + 1)`：访问下一个字符的值。
- `str[1]`：与 `*(str + 1)` 等价。

**核心理解：字符串字面量是字符数组，数组作为函数实参时通常会自动转换为首元素指针，而 `printf` 正是通过这个指针找到并读取字符串的。**

### 标识符有哪些种类？

| 类别 | 例子 | 是否为标识符 |
|---|---|---|
| 变量名 | `age` | 是 |
| 函数名 | `printf` | 是 |
| 结构体标签 | `CPU`（`struct CPU`） | 是 |
| 结构体成员名 | `pc` | 是 |
| 类型别名 | `Integer`（`typedef int Integer;`） | 是 |
| 关键字 | `int`、`return` | 否 |

**总结：标识符（Identifier）是程序中用于命名变量、函数、类型别名等实体的名字。变量名属于标识符，但标识符不一定是变量名。**
