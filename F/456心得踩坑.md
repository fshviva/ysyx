## （二）
<details>
<summary>激励事件与状态转移规则的区别</summary>

### 1. 三个概念

- **状态**：当前是什么？
- **激励事件**：执行什么？
- **状态转移规则**：执行后状态如何改变？

### 2. 举例

```c
if (i < 10) {
    sum = sum + i;
}
```

- **状态**：当前 `i` 和 `sum` 的值。
- **激励事件**：执行整个 `if` 语句。
- **状态转移规则**：
  - 如果 `i < 10`，执行 `sum = sum + i`。
  - 否则跳过加法，`sum` 不变。

**不同初始状态的结果：**

- `(i, sum) = (5, 10)` → `(5, 15)`
- `(i, sum) = (12, 20)` → `(12, 20)`

### 3. C程序与ISA的区别

| 概念 | C程序 | ISA |
|---|---|---|
| 激励事件 | 执行语句 | 执行指令 |
| 状态转移规则 | 语句的语义 | 指令的语义 |

### 4. 核心总结

> **激励事件 ≠ 状态转移规则**
>
> - 激励事件：发生了什么。
> - 状态转移规则：发生事件后，状态应该如何变化。
> - 相同的规则，在不同初始状态下，可能得到不同的结果。

## （三）ISA、汇编语言和机器码的区别
| 名称 | 是什么 | 例子 |
|---|---|---|
| ISA（指令集架构） | CPU 执行指令时遵循的一套规则，包括指令编码（如规定 00 代表 add）、执行效果等 | RISC-V、ARM |
| 汇编语言 | 用文字、符号表示机器指令 | `add x1, x2, x3` |
| 机器码 | 按照 ISA 规则编码的二进制指令 | `0000000...0110011` |
